# Operating summary

Re-read this on long runs. Do not reload the giant builder prompt.

## Runtime

Cursor agent wrapping this repo. Marketing site only. Portal is a different app.

## Default architecture

One generalist (this agent). File-first state in `.agent/`. Verify before done. No swarm. No second product.

```
goal -> task -> execute -> verify -> update .agent/ -> next
```

## First milestone (this run)

Prove the loop. Inventory every public CTA / intake href. Write `.agent/artifacts/cta-map.md`. Pass `.agent/evals/verify.mjs`.

## Guardrails

- Men and women, 18–80. Not men-only.
- No new `/intake` routes. No named medications. No outcome claims.
- Do not paste mega-prompts into `AGENTS.md`.
- Do not build a hub, SQLite, workers, or company OS in this repo.
- Other businesses stay out.

## Constraints

Healthcare advertising law. Token cost is the failure mode. One chat, one job.
